# Documentation · Documentación

All documentation is maintained in **English** and **Spanish**. Both versions
are kept in step; when they disagree, the English copy is authoritative for
technical detail and the Spanish copy for terminology used in the laboratory.

Toda la documentación se mantiene en **inglés** y **español**. Ambas versiones
se mantienen sincronizadas; ante una discrepancia, la copia en inglés manda en
el detalle técnico y la española en la terminología de laboratorio.

## Translation policy · Política de traducción

Translations are idiomatic, not literal. Technical identifiers — table names,
command letters, JSON fields, HTTP paths — are **never** translated, because a
reader has to be able to match the document against the code and the database.
Prose explaining *why* a decision was taken is rewritten in the target language
rather than transliterated.

Las traducciones son idiomáticas, no literales. Los identificadores técnicos
—nombres de tablas, letras de comando, campos JSON, rutas HTTP— **nunca** se
traducen, porque el lector tiene que poder cotejar el documento con el código y
la base de datos. La prosa que explica *por qué* se tomó una decisión se
reescribe en el idioma destino en lugar de transliterarse.
